# 정적 파일 저장 폴더

이 폴더에 아래 파일들을 넣어주세요:

1. `사업자등록증.pdf` - 사업자등록증 PDF 파일
2. `통장사본.jpg` - 통장사본 이미지 파일  
3. `위탁계약서.hwp` - 위탁계약서 HWP 파일

이 파일들은 Vercel에 정적으로 호스팅되어 
Apps Script에서 직접 다운로드하여 메일에 첨부합니다.

접근 URL 예시:
- https://your-domain.vercel.app/static/사업자등록증.pdf
- https://your-domain.vercel.app/static/통장사본.jpg
- https://your-domain.vercel.app/static/위탁계약서.hwp
